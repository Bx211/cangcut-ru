# cangcut-ru
Toolkit CLI Ruby.


## Instalasi
bundle install

## Cara Pakai

./bin/cangcut to-int "123" ./bin/cangcut split - "a-b-c-d" ./bin/cangcut uniq 1 2 1 3 2 4 ./bin/cangcut sha256 "halo dunia" cat sample.json | ./bin/cangcut pretty-json

## Fitur
- Konversi aman ke integer
- Split string
- Unique list
- Hash SHA256
- Prettify JSON
